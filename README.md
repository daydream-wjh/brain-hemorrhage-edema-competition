# e —— 脑出血 / 水肿影像数据竞赛工作区

> 一个医学影像数据挖掘竞赛的原始工作目录：数据、两段探索性 notebook、两个 MATLAB 遗留文件。
> **当前状态：数据已就位，建模尚未开始。** 本 README 按实际代码内容撰写，不含任何成绩宣称。

## 项目简介

这个仓库是某次**脑出血（ICH）与血肿周围水肿（ED）**数据挖掘竞赛的参赛工作区。赛题需要围绕 `竞赛发布数据/` 里的四张表，回答三个问题：

1. **血肿扩张**：入院后是否发生血肿扩张、扩张发生在何时；
2. **水肿体积进展曲线**：预测随访期间水肿体积的演变（按残差评价，分全体与亚组）；
3. **预后预测**：基于首次影像（及随访）预测 90 天 mRS 评分。

仓库里的代码量很小：`main.py` 是 PyCharm 新建工程时自动生成的模板脚本，两个 notebook 只做了"读表 + 少量异常值清洗"，没有任何模型训练、交叉验证或提交文件生成的代码。想复现一份有成绩的方案，需要从这个骨架继续写。

## 数据集说明

所有数据在 `竞赛发布数据/` 下，均为 `.xlsx`（共 5 个文件）。行数/列数取自实际读取结果。

### 表1 - 患者列表及临床信息.xlsx

Sheet `患者信息`，**160 行 × 23 列**，一行为一位患者。

| 字段 | 说明 |
| --- | --- |
| `Unnamed: 0` | 患者编号，`sub001` … `sub160`（原表首列没有列名） |
| `90天mRS` | 90 天改良 Rankin 量表评分，0–6；**测试集患者为空** |
| `数据集划分` | `训练` 100 例 / `测试1` 30 例 / `测试2` 30 例 |
| `入院首次影像检查流水号` | 14 位数字流水号，是跨表连接的主键 |
| `年龄` | 岁 |
| `性别` | `男` / `女`（110 / 50） |
| `脑出血前mRS评分` | 发病前基线 mRS |
| `高血压病史`、`卒中病史`、`糖尿病史`、`房颤史`、`冠心病史`、`吸烟史`、`饮酒史` | 0/1 二值病史 |
| `发病到首次影像检查时间间隔` | 小时（小数） |
| `血压` | **字符串**，形如 `180/90`，需自行拆分收缩压/舒张压 |
| `脑室引流`、`止血治疗`、`降颅压治疗`、`降压治疗`、`镇静、镇痛治疗`、`止吐护胃`、`营养神经` | 0/1 二值治疗记录 |

### 表2 - 患者影像信息血肿及水肿的体积及位置.xlsx

Sheet `Data`，**160 行 × 208 列**，宽表结构，一次检查占一组列。

- 主键列：`ID`（`sub001` 风格）、`首次检查流水号`。
- **首次检查**（22 列）：`HM_volume`、`ED_volume`，以及 `HM_` / `ED_` 各 10 个分区占比：

  | 后缀 | 含义 |
  | --- | --- |
  | `_ACA_` / `_MCA_` / `_PCA_` | 大脑前 / 中 / 后动脉供血区 |
  | `_Pons_Medulla_` | 脑桥与延髓 |
  | `_Cerebellum_` | 小脑 |
  | `_R_` / `_L_` | 右 / 左半球 |

  即 `HM_ACA_R_Ratio` 形如「血肿在右侧 ACA 区的体积占比」。数值落在 0–1 区间（实测 `HM_ACA_R_Ratio` 为 0 ~ 0.496），体积单位为体素计数（`HM_volume` 实测 1314 ~ 242502）。
- **随访**（`随访1` … `随访8`，每组 23 列）：`随访i流水号` + 同上一整套 `HM_*` / `ED_*` 字段，pandas 读入后会带 `.1` … `.8` 后缀。全部 8 次随访共 **433 条**记录，只有 2 例做到随访 8。
- `HM` = 血肿（Hematoma），`ED` = 水肿（Edema）。

> 注意：随访流水号列因存在空值会被 pandas 读成 `float64`（`2.016121e+13`）。与其他表 join 前需转成整型或字符串，否则精度/类型不匹配。

### 表3 - 患者影像信息血肿及水肿的形状及灰度分布.xlsx

三个 sheet，**长表**结构，一行为一次检查（`流水号` 唯一）：

| Sheet | 行数 | 内容 |
| --- | --- | --- |
| `ED` | 576 | 水肿病灶的影像组学特征 |
| `Hemo` | 545 | 血肿病灶的影像组学特征 |
| `Sheet1` | 31 | 特征名清单（表头误写成 `流水号`，实际内容是 31 个特征名，无数据） |

`ED` / `Hemo` 两表列结构相同，共 33 列：`备注`（全为空，占位列）、`流水号`，加 31 个特征：

- **3D 形状特征（14 个）**：`original_shape_Elongation`、`Flatness`、`LeastAxisLength`、`MajorAxisLength`、`Maximum2DDiameterColumn`、`Maximum2DDiameterRow`、`Maximum2DDiameterSlice`、`Maximum3DDiameter`、`MeshVolume`、`MinorAxisLength`、`Sphericity`、`SurfaceArea`、`SurfaceVolumeRatio`、`VoxelVolume`。
- **一阶灰度统计（17 个）**：`NCCT_original_firstorder_*` —— `10Percentile`、`90Percentile`、`Energy`、`Entropy`、`InterquartileRange`、`Kurtosis`、`Maximum`、`MeanAbsoluteDeviation`、`Mean`、`Median`、`Minimum`、`Range`、`RobustMeanAbsoluteDeviation`、`RootMeanSquared`、`Skewness`、`Uniformity`、`Variance`。

命名风格与 **PyRadiomics** 的 `shape` / `firstorder` 特征类一致（`NCCT` 指平扫 CT 序列），说明这些特征是在分割掩膜上离线提取后导出的，仓库内**不含**提取脚本。

### 表4 - 答案文件.xlsx

Sheet `Sheet1`，**162 行 × 10 列**，这是**提交模板**，不是答案——除编号与流水号外所有答案列均为空。

前 3 行是两级表头：

| 列 | 三级表头 | 含义 |
| --- | --- | --- |
| 0 | （空） | 患者编号 `sub001` … `sub160` |
| 1 | `首次影像检查流水号` | 主键 |
| 2–4 | **问题1：血肿扩张** | `是否发生血肿扩张`（1 是 / 0 否）、`血肿扩张时间`（单位：小时）、`血肿扩张预测概率` |
| 5–7 | **问题2：水肿体积进展曲线** | `残差（全体）`、`残差（亚组）`、`所属亚组` |
| 8–9 | **问题3：预后预测建模** | `预测mRS（基于首次影像）`、`预测mRS` |

从列设计可以反推评分口径的方向：问题1 交「概率 + 二分类 + 时间」，应按概率排序类指标 + 时间误差评价；问题2 交「残差」，属回归误差类；问题3 交「mRS 预测值」，属有序等级预测。**具体指标定义与权重不在此仓库中**，需以竞赛官方说明为准。

### 附表1 - 检索表格-流水号vs时间.xlsx

Sheet `Sheet1`，**162 行 × 108 列**，是流水号与检查时间的对照表。

- `ID`：注意这里的编号是 `Hemo0001` 风格，**与表1/表2 的 `sub001` 体系不同**，只能靠流水号 join。
- `重复次数`：该患者总检查次数，实测分布为 2 次 6 例、3 次 66 例、4 次 35 例、5 次 31 例、6 次 15 例。
- 时间/流水号成对出现：`入院首次检查时间点` + `入院首次检查流水号`，`随访1时间点` + `随访1流水号` … 一直到 `随访13`。时间格式为 `2016-12-12 23:32:54`，可直接用于计算随访间隔。
- 第 31 列之后（`Unnamed: 30` … `Unnamed: 107`）为空白列。

### `1.ipynb`（唯一有实际逻辑的 cell）

```python
df = pd.read_excel('表1-患者列表及临床信息.xlsx')
df.drop(['ID', '首次检查流水号'], axis=1, inplace=True)
df = df[(df['HM_volume'] > 0) & (df['ED_volume'] > 0)]
df.loc[(df['HM_ACA_R_Ratio'] < 0) | (df['HM_ACA_R_Ratio'] > 1), 'HM_ACA_R_Ratio'] = 0
df.loc[(df['HM_MCA_R_Ratio'] < 0) | (df['HM_MCA_R_Ratio'] > 1), 'HM_MCA_R_Ratio'] = 0
df.loc[(df['HM_PCA_R_Ratio'] < 0) | (df['HM_PCA_R_Ratio'] > 1), 'HM_PCA_R_Ratio'] = 0
```

意图是：丢掉编号列 → 剔掉血肿或水肿体积非正的样本 → 把取值越出 [0,1] 的分区占比当作脏数据抹成 0。

**但这段代码直接跑不通**：`表1` 里既没有 `ID`、`首次检查流水号`，也没有 `HM_volume` / `ED_volume` / `*_Ratio`——这些字段在 `表2`。注释里列了 10 个 `HM_*_Ratio` 字段，代码只写了右侧 3 个（`ACA/MCA/PCA_R`），左侧 5 个与 `ED_*` 全部漏掉。可以判断这个 cell 是对着「已经 merge 过表1+表2 的宽表」写的，而不是对 `表1` 原始文件。


运行 notebook 前必须先改两处，否则跑不通：

1. `1.ipynb` 的路径改成 `竞赛发布数据/表1-患者列表及临床信息.xlsx`；
2. `1.ipynb` 第一个 cell 里的 `drop` / 过滤条件要改成表2 的字段名，或者先把表1、表2 按流水号 merge 成宽表再执行（原意应是后者）。

正确的主键连接方式：

```python
t1 = pd.read_excel('竞赛发布数据/表1-患者列表及临床信息.xlsx')
t2 = pd.read_excel('竞赛发布数据/表2-患者影像信息血肿及水肿的体积及位置.xlsx')
t1['key'] = t1['入院首次影像检查流水号'].astype('int64')
t2['key'] = t2['首次检查流水号'].astype('int64')
df = t1.merge(t2, on='key', suffixes=('', '_t2'))
```

`表3` 是长表，按 `流水号` 与 `表2` 的 `首次检查流水号` / `随访i流水号` 关联即可把影像组学特征挂到每个时间点上。
